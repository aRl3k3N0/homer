# Shell / REPL

```bash
homer shell
```

Доступно:

* Прямой ввод команд Homer (без префикса).
* Python-выражения и код.
* Специальные команды с ```:```.

## Специальные команды

| Команда                   | Что делает                  |
|---------------------------|-----------------------------|
| ```:help```               | Справка                     |
| ```:list```               | Список команд Homer         |
| ```:run <cmd> [args]```   | Выполнить команду Homer     |
| ```:reload```             | Перечитать ```config.yml``` |
| ```:ctx```                | Показать контекст           |
| ```:clear```              | Очистить экран              |
| ```:exit``` / ```:quit``` | Выход                       |

## Пример

```shell
>>> app.name                        # ошибка, нет переменной app
>>> config.get('app.name')
'Homer'
>>> print(console.bold('Привет'))
Привет
>>> :list
>>> idm --user=admin --ver=16       # выполнить команду Homer
>>> :run cmdb:update --user=cmdb
>>> :exit
```

## Доступные объекты

В Python-режиме доступны:

* ```config``` — объект ```Config```.
* ```logger``` — ```Logger```.
* ```console```, ```Color```.
* ```root_dir``` — ```Path```.
* ```commands``` — словарь команд.
* ```ctx``` — полный контекст.

## Управление

* ```Ctrl+C``` — прервать ввод.
* ```Ctrl+D``` — выход.
* Пустая строка — ничего.
